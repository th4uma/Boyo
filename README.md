# Boyo

Windows 本地照片精简与图集整理工具。

Boyo 将相似照片归组，标出疑似模糊、虚焦和曝光异常的照片，方便对照筛选。已挑出的精选会受到保护，日常的保留、待删操作也会用于学习你的筛图习惯。

**当前版本 0.8.7 · 原生 PySide6 界面 · 本地分析 · MIT 许可**

名字取自 toe 的同名曲目。

## 功能

| 工作区 | 主要功能 |
| --- | --- |
| 照片精简 | 相似构图分组、废片筛查、保留与待删复核、高强度二次筛查 |
| 文件工具 | 精选 RAW 补齐与清理、孤立 RAW 整理、操作记录与恢复 |
| 自动图集 | 自动选图、封面与锁定位置、换图排序、副本导出、XMP 参考修图 |

## 安装与启动

运行环境为 Windows x64，已在 Python 3.11 上验证。安装 Python 3.11 或更新版本，将源码放入照片工作区的 `tools/Boyo/repo` 目录。

在源码目录打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\安装环境.ps1
```

脚本会建立运行环境并下载依赖，其中 DINOv2 Small 权重约 88 MB。首次安装需要联网。

安装完成后，双击源码目录中的 **启动Boyo.cmd**。

## 照片目录约定

工作区里每个一级文件夹算一个拍摄组。普通 JPG 可以放在组内的 `jpg` 文件夹，也可以直接放在组内根目录：

```text
照片工作区/
  一次旅行/
    jpg/                     普通 JPG
    raw/                     对应 RAW、XMP
    精选/
      jpg/                   手动复制进来的精选 JPG
      raw/                   可用文件工具补齐
    成片/                    修好的照片，可作为图集封面
    deleteraw/               RAW、XMP 移动备份，按需创建
    图集/                    图集副本导出，按需创建
  已删除备份/
    一次旅行/                待删 JPG 移到这里，直接存放文件
```

挑出精选时，将 JPG 复制到 `精选/jpg`，普通 JPG 继续保留在原处。扫描后，Boyo 会保护精选、成片和它们对应的原片；全景等附加图片也默认保留。修图后改过名字的成片，可以在图库里用“关联原片”指定来源。

RAW 按同组内的唯一名称关系配对，再结合相机和拍摄时间核对。日常扫描会跳过备份和图集导出目录。

## 使用流程

选好工作区和拍摄组，点击“扫描并分析”。第一次会读取照片、计算图像特征；之后复用未变化的文件和缓存。

相似复核把相近构图放在同组，可以逐张保留、待删，也可以采纳本组建议或整组处理。废片筛查单独列出疑似模糊、虚焦、运动拖影和曝光异常的照片。缩略图直接滚动，双击或按 Enter 打开大图，用左右键比较；做完决定会停留在当前照片。

完成一轮后，进入“待删复核”。底部的“执行删除”会直接核对清单，将 JPG 和匹配的 RAW / XMP 移到备份。配对有歧义、照片受保护或目标位置冲突时，对应项目会暂缓，并在页面里显示原因。

需要进一步精简时，从“更多”运行“高强度二次筛查”。这一轮会重新检查剩余的未分类和保留照片，计算时忽略普通保留标签，继续保护精选。复核后再更新照片状态。

扫描、分析和 RAW 检查在后台进行，期间可以继续看图和标记，任务结束后自动刷新列表。

| 按键 | 操作 |
| --- | --- |
| K / D | 保留 / 标记待删 |
| U 或 Ctrl+Z | 撤销当前照片的决定 |
| ← / → | 大图内切换照片 |
| Home / 1 | 大图适应窗口 / 原始像素检查 |

## 文件处理

保留和待删按钮记录你的决定；点击执行后，文件才按下面的位置处理：

| 操作 | 文件处理 |
| --- | --- |
| 执行删除 | JPG 移到 `已删除备份/拍摄组/`，关联 RAW / XMP 移到本组 `deleteraw/` |
| 整理孤立 RAW | 将缺少对应普通 JPG 的 RAW 及配套 XMP 移到本组 `deleteraw/` |
| 补齐精选 RAW | 从普通 RAW 复制到 `精选/raw/`，同时把已无对应精选 JPG 的旧 RAW / XMP 副本移到 `deleteraw/` |
| 导出图集 | 复制到 `图集/图集名/` |
| 一键修图 | 导出新副本到 `图集/图集名_调色/`，重名时另建目录 |

每次执行都会核对保护关系、文件内容和目标位置，逐项记录处理结果。已有目标文件保留原样，移动过的文件可在“操作记录与恢复”中找回。照片移到同盘备份后仍占用磁盘空间。

## 自动学习

学习样本来自照片精简里的主动留删和纠正操作。每张照片按当前有效选择计入样本，撤销决定也会撤下对应标签，照常筛图就能积累记录。

画面特征使用冻结的 DINOv2 Small，个人偏好由 scikit-learn 的轻量模型学习。积累一批新选择、停止操作约 12 秒后，后台开始验证；继续筛图时暂停，扫描和文件整理优先。技术容忍按相机分别验证，换相机后先沿用基础指标，再逐步积累新样本。

顶部“偏好”里可以查看有效反馈、最近验证时间、排序效果和已经启用的学习项。通过验证的项目会用于后续分析，你已经作出的决定继续保留。

## 自动图集与参考修图

自动图集把照片整理成一组地点记录，默认约 9 张。首图从成片中选，第二张也可以用成片，其余从普通 JPG 中补充不同构图、不同色彩的画面。

你可以自己换图、排序。手动加入的照片默认锁定，“自动补齐空位”保留已有位置，“重做未锁定项”替换未锁定的位置。同一张原片及其关联版本在全部图集中使用一次，照片不足时留空。

“一键修图”以封面为参考，优先复用 Camera Raw XMP 中的全局白平衡、曝光、曲线和调色，再逐张调整曝光与色调。RAW 渲染调用本机安装的 Photoshop / Camera Raw；缺少唯一匹配 RAW 的照片改用 JPG 参考匹配，并显示提示。

修图和导出都生成副本，封面原样复制，结果放在本组的 `图集` 目录。原照片和原 XMP 继续保留。
