# 版本记录

## 0.8.7

- 将 Python 包名、项目元数据、启动环境变量与内部对象名称统一为 Boyo。
- 同步修正测试、文档及打包资源路径，沿用现有状态库和个人模型。
- 启动时兼容读取旧环境变量、环境位置标记和旧实例通信地址。

## 0.8.6

- 修复缩略图中的保留、待删和撤销入口；相似复核增加选中照片留删，保留原整组操作。
- 废片筛查增加疑似运动模糊、手抖拖影，单独升级质量测量缓存。
- 图集新增一键修图：优先复用封面 XMP，使用本机 Adobe 渲染临时 RAW 副本，再做有界曝光和色调匹配，导出新副本。

## 0.8.5

- 增加高强度二次筛查，重新评估未分类和保留照片；普通保留标签只在计算中忽略，精选保护继续生效。
- 为采纳建议增加复核时间和文件身份校验，人工重新确认会使旧建议失效。
- 文件删除增加分阶段进度，在 Windows NTFS 上按目录变更通知复用未变化的保护检查。

## 0.8.4

- 应用更名 Boyo，更新蓝紫色原创图标与启动入口；保留既有运行数据和内部包名。

## 0.8.3

- 相似复核固定整组操作，移除常驻操作提示。
- 统一同一缩放档位下的卡片尺寸、边框与换行规则。

## 0.8.2

- 修复操作记录和学习详情的空白显示，增加分批加载历史记录。
- 学习详情显示有效反馈、验证比较数、启用项及未启用原因。

## 0.8.1

- 恢复相似组独立列表，修正当前列表的状态计数。
- 图集导出区可收起，刷新保持原展开状态。
- 补齐精选 RAW 时同时清理已无对应精选 JPG 的旧 RAW / XMP 副本。

## 0.8.0

- 以原生 Qt 实现新的三工作区布局，运行时不嵌入网页。
- 扫描、分析、删除与恢复完成后自动刷新，并保留照片位置。

## 0.7.x

- 整理照片精简、文件工具和自动图集工作区；RAW 检查与执行直接集成在页面内。
- 统一滚动缩略图、双击大图、左右键浏览及留删停留行为。
- 扫描和文件检查放入有界后台队列，其他照片继续可操作。

## 0.6.x

- 正常留删行为自动积累反馈，在独立低优先级进程验证个人模型。
- 增加独立 Python 环境及工作区迁移识别，保留数据库身份与恢复记录。

## 0.5.x

- 增加独立废片筛查与敏感度设置。
- 合并有构图关联的复核组，同时维持逐张直接匹配的删减证据。

## 0.4

- 相似筛查引入局部特征与构图几何校验，增加技术质量提示。
